### Featured Projects

**[outbreak-agent](https://github.com/ankurgenomics/outbreak-agent)**
4-node LangGraph triage pipeline for infectious disease outbreaks. Built around the
April 2026 MV Hondius / Andes virus event. Generates a risk dashboard (PNG) and
structured PDF triage report automatically. 33 tests, no API key required.

- LangGraph 0.6 state machine with conditional critic loop
- Deterministic triage: genomic analysis, contact linkage, risk scoring, self-correction
- `pytest tests/test_nodes.py tests/test_graph.py -v` -- 33 passed, free to run

Agentic genomics platform connecting sequencing pipelines to clinical decision support.
